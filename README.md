# 股灾雷达

10 个股灾预警指标，红黄绿灯 + 一句大白话 + 影响板块 + 历史上准不准。

- **电脑**：双击 `启动股灾雷达.bat`，点「刷新」= 现场抓最新数据重算（约 3 秒）。
  每次刷新还会生成 `export/股灾雷达-快照.html`，放云盘双击就能看。
- **手机**：打开 GitHub Pages 网址 → 分享 →「添加到主屏幕」。云端每 30 分钟自动重算，
  手机上的「刷新」拉取云端最新结果。

| 组 | 指标 | 数据 |
|---|---|---|
| 贵不贵 | 巴菲特指标、席勒市盈率、股债性价比 | 美联储 Z.1 + GDP、席勒 |
| 经济会不会衰退 | 收益率曲线（10Y−3M）、萨姆规则、初请失业金 | FRED（收益率曲线备用：美国财政部） |
| 现在有没有在出事 | 企业债利差、金融压力指数、VIX、大盘趋势 | FRED、Yahoo（VIX 备用：CBOE） |

**怎么检验准不准**：「暴跌」＝某月底起一年内标普 500 跌 ≥20%。比较「亮红灯的月份后来暴跌的比例」和
「所有月份的比例」，并看 1929 年以来 15 次熊市里，跌满 10% 之前有没有亮过红灯。红黄灯门槛都是事先
定好的常用标准；回测里每个时点只用当时已公布的数据（季度数据按 90 天、月度按次月、周度按 5 天延迟）。
月份重叠、熊市次数少，这些数字只能当参考。

`log/` 是云端每天记一笔的灯，攒下来就能做真正的「事前」检验。

```
python run.py --cli        # 终端打印
python run.py --publish    # 生成 site/（GitHub Actions 用）
```
